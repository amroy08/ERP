# Phase 4.1E: Reminder Rules UI Notes

The **Reminder Rules** tab is the configuration panel for alert systems.

## Features
1. **Rule Selection Cards**:
   * Separate premium layouts for **Fee Pending / Overdue Reminder** and **Repeated Absences Alert**.
2. **Interactive Toggles & Switches**:
   * Enable or disable rules dynamically.
3. **Numeric Parameter Configuration**:
   * Cooldown hours, lookback windows, and threshold limits.
4. **Validation Integrity**:
   * Validates values client-side to ensure negative bounds are blocked.
   * Prompts error messages/toast notifications for bad input constraints.
