# Before/After Scope Notes

This document clarifies the boundary of scope for Phase 3.3B: Mobile Design System Foundation.

## Active Scope (Phase 3.3B)
- **Design Token System**: Introduced centralized layout, spacing, colors, gradients, typography, and shadow tokens.
- **Component Refactoring**: Upgraded core components (AppButton, AppCard, AppInput, ScreenContainer, StatusBadge, EmptyState, ErrorState) to pull styles dynamically from design tokens.
- **Icon Polish**: Removed basic emojis from tab navigators and replaced them with professional Ionicons.
- **Redesigned Login Interface**: Complete visual overhaul of the mobile Login screen including backgrounds, typography, and interactive chips.

## Deferred Scope (Phase 3.3C onward)
- **Teacher/Student/Parent Dashboard Redesign**: The full redesign of interior dashboard layouts, custom widgets, specific module listings, and secondary workflows is **intentionally deferred to Phase 3.3C onward**.
- **Existing Dashboard Workflows**: Left completely intact with 100% backward compatibility to avoid visual regressions or functional disruptions during the design system foundation rollout.
