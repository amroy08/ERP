# Next Feature Priority List

This list identifies and ranks upcoming candidate features and module expansions to further enhance web-mobile parity and user convenience.

---

## 🚀 Priority Rankings

### 1. Direct FCM Notices Push Alerts (P1 - Required for MVP parity)
* **Feature**: Real-Time Notice Push Alerts
* **Current Web Status**: Supported (Logs notifications on notice creation).
* **Current Mobile Status**: Supported (Device FCM registration token endpoints exist).
* **Risk**: High priority notice announcements are not delivered instantly to parents/teachers as lock-screen alerts.
* **Recommended Phase**: Phase 3.2I (Alerts Optimization)
* **Estimated Complexity**: Medium

### 2. Student Notices Detail Screen (P2 - Useful but can wait)
* **Feature**: Student Notices Detail Screen
* **Current Web Status**: Fully supported.
* **Current Mobile Status**: Partial (Dashboard lists titles and priorities, but has no details sub-view).
* **Risk**: Students miss long-text instructions or details from school announcements.
* **Recommended Phase**: Phase 3.2J (Student Mobile Alignments)
* **Estimated Complexity**: Low

### 3. Notice File Attachment Downloads on Mobile (P2 - Useful but can wait)
* **Feature**: Notice PDF/Image Downloads on Mobile
* **Current Web Status**: Supported (notices can include files).
* **Current Mobile Status**: Missing (notice screens show text only).
* **Risk**: Parents and teachers cannot download official circular PDFs directly on their mobile devices.
* **Recommended Phase**: Phase 3.2K (Notices File Sync)
* **Estimated Complexity**: Low

### 4. Mobile Parent Online Fee Payments Integration (P2 - Useful but can wait)
* **Feature**: Mobile Online Payments (Razorpay/Stripe Integration)
* **Current Web Status**: Partial (Admin records collections manually; no direct payment gateways).
* **Current Mobile Status**: Missing (Read-only billing information).
* **Risk**: Parent convenience is restricted to physical/desktop options.
* **Recommended Phase**: Phase 3.3 (Payment Gateways Integration)
* **Estimated Complexity**: High

### 5. Student Daily Attendance Logs View (P3 - Optional / future)
* **Feature**: Student Monthly Attendance Calendar
* **Current Web Status**: Supported.
* **Current Mobile Status**: Missing (Displays summary percentage on dashboard only).
* **Risk**: Students cannot cross-reference which specific dates they were marked absent or late.
* **Recommended Phase**: Phase 3.4 (Student Attendance Expansion)
* **Estimated Complexity**: Low
