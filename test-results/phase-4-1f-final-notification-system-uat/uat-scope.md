# Phase 4.1F: UAT Scope

Scope definition for the Notification System User Acceptance Testing.

## Areas Verified
1. **Backend Notification REST API**: Core endpoints, parameter checks, paginations, and metadata structures.
2. **Event-Based Triggers**: Automated notifications created upon homework postings, circular notices, exam configurations, marks publishing, and absence limit counts.
3. **Fee and Absence Scheduler**: Automatic lookbacks, threshold parameters, target limits, and cooldown gates.
4. **Mobile Console User Experience**: Dashboard badges, unread trackers, list rollouts, mark single/all as read operations, and pull-to-refresh.
5. **Web Settings Dashboard**: Rule toggles, lookback configuration limits, filtering grids, manual scans, and safe audit visibility.
6. **Role Guarding & Security Isolation**: Access limits guarding settings pages, role-based logs visibility, and parent-child correlation rules.
7. **Spam Prevention & Cooldown Gating**: Cooldown hours verification and duplicate triggers blocks.
